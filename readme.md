# Extraordinary Specials

A WordPress component for presenting hospitality offers with validity dates, prices, package details and an image gallery, with property-specific enquiry integration.

## For recruiters

This repository is a public code snapshot associated with **Papi Mashamba's website integration, adaptation and rollout work**. It shows how offer content and enquiry entry points fit into a wider marketing and customer-journey programme.

The documented October 2026 delivery covered nine property installations, with eight active enquiry embeds retained. That delivery record is separate from this historical repository snapshot; this branch is not a verified mirror of every live installation.

[Read the marketing value-stream case](https://github.com/thepotentguy/digital-transformation/blob/main/case-studies/marketing-value-stream.md) · [Papi's profile](https://github.com/thepotentguy)

## Features

- Offer validity dates, pricing and packages.
- Image galleries and property presentation.
- WordPress templates and configurable brand styling.
- Property context passed to enquiry-related scripts.

## Installation and use

1. Review the code and dependencies against your WordPress and PHP versions.
2. Install in a controlled development or staging environment.
3. Configure property settings and verify the offer and enquiry journey before release.

The offer fields appear in the post editor and plugin settings. Production deployment requires environment-specific review; this portfolio update changes documentation only.
